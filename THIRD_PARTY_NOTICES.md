# Third-party notices

Bode_Metrics contains no third-party source code. It is written from scratch against the OpenTelemetry metrics API
and Magento's public classes.

It shares its deployment story with Bode_Tracing, part of which started as a copy of
https://github.com/mumzworld-tech/magento2-opentelemetry (MIT); that notice is
the notice of the `bode/module-tracing` package (`THIRD_PARTY_NOTICES.md` and `LICENSE-UPSTREAM-MIT`). Nothing from it
needs to travel along with this package.
